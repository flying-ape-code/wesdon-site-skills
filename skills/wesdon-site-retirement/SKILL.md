# 客户站点下线

下线会永久影响客户数据。仅在用户明确写明目标站点及删除/保留范围后执行；“不用了”或“清理一下”不足以授权删除。

## 删除前

1. 读取并展示目标实例标识、域名、端口、数据库名、容器、上传目录、备份数量与 cron 任务。
2. 复核其他站点不共享这些资源，并检查其健康状态。
3. 确认客户是否保留最终备份；若授权永久删除备份，在“发布与变更”写明不可恢复。
4. 不删除共享 PostgreSQL、共享网络、共享镜像、仓库或其他客户资源。

## 删除顺序

停止并删除目标容器；断开该实例的定时任务；终止目标数据库连接并删除目标数据库和角色；最后删除目标实例目录、上传目录、该客户备份目录与专属日志。

## 删除后

只读验证目标容器、实例目录、数据库、角色、备份目录和 cron 均不存在；确认保留站点健康。向“发布与变更”记录授权来源、删除范围、结果和恢复状态。
