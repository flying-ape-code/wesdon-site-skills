# 多网站巡检与台账同步

企业微信《官网运维总台账》是团队协作入口，生产环境是运行事实来源。台账不可保存密码、数据库 URL、SSH 信息、管理员密码或备份文件内容。

## 表格约定

从操作员的受管配置读取 `WECOM_SITE_OPS_TABLE_URL`，不要把表格 URL 或凭据硬编码进仓库。

- “站点总览”：每个 `站点标识` 仅一行，更新运行状态、环境、域名、端口、备份状态、待办、最后同步时间。
- “巡检记录”：每次巡检新增记录，保留健康接口、容器、备份、结果、发现与处理、执行人。
- “发布与变更”：仅记录已授权的发布、回滚、下线等操作。

写入前先读取字段与现有记录。智能表格记录使用字段标题而非字段 ID；单选字段使用已有选项 ID 或明确文本。

## 巡检流程

1. 只读列出实例目录、容器状态、回环端口、`/api/health`、最新备份归档与备份时效。
2. 对公网域名额外检查 DNS、HTTPS、首页与健康接口；内部临时站点不得误标为公网开放。
3. 标记“通过 / 告警 / 待核验”，并描述可验证事实，不猜测备案、证书或内容合规状态。
4. 更新“站点总览”；每次新增“巡检记录”。异常仅报告和告警，不自动重启、修复或删除。
5. 汇总站点数量、健康/告警数量、备份新鲜度和必须人工处理的事项。

## 异常升级

出现健康接口失败、容器不健康、备份缺失/过期、证书即将到期或公网不可访问时，先保存检查证据，写入台账并通知发布负责人。任何重启、更新、数据库操作或凭据重置必须转交相应 Skill 并取得明确授权。
